# 🎮 Gaming Computers Sale Page

Detta projekt är en **responsiv reklamsida** för gamingdatorer. Den är byggd med **HTML, CSS och JavaScript**, och demonstrerar moderna webbutvecklingsprinciper som smidig scrollning, responsiv design och interaktiva element.

---

## 🚀 Funktioner

- **Modern layout:** Enkla sektioner med tydlig navigation (`Features`, `Demo`, `Pricing`).
- **Smidig scrollning:** Länkar i menyn scrollar mjukt till rätt sektion.
- **Responsiv design:** Logotypen döljs automatiskt på mindre skärmar (t.ex. mobiler).
- **Inbäddad video:** En demo-video som visar gamingdatorn i aktion.
- **Nyhetsbrev:** Formulär där besökare kan skriva upp sig för exklusiva erbjudanden.
